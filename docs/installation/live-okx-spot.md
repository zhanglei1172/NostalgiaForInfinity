# OKX 现货实盘：在网页配置

Docker 只负责启动管理服务。管理员账号、OKX 密钥和资金预算均在网页填写，
无需把这些值放入 Compose、`.env`、启动命令或脚本。所有命令在仓库根目录执行。

## 启动管理后台

```bash
docker compose build freqtrade
docker tag nfi-paper:local nfi-paper:live-candidate
docker compose up -d --no-build --pull never backtesting
install -d -m 700 user_data/live-okx
docker compose -f docker-compose.live.yml -p nfi-live up -d
```

打开 `http://127.0.0.1:18081`。首次访问会进入管理员创建页面，设置用户名和密码，
随后登录。首次管理员创建仅允许使用本机地址；没有通用默认密码，也不会在日志中打印登录密码。
管理员密码以 scrypt 哈希保存，可以在“账户与安全”修改。

此时只运行管理后台，尚无交易进程。模拟盘继续使用 `18080`，两套服务的账号和账本相互独立。
策略库、回测和策略配方在未配置 OKX 账户时也可访问。研究服务与模拟盘复用同一个
`backtesting` 容器，通过私有 `nfi-research` 网络访问，不增加容器或公开端口。
若单独启动实盘，也需先执行上面的 `backtesting` 启动命令以建立研究网络。

默认直接连接 OKX，不启动代理容器。容器 DNS 默认为 `1.1.1.1`，可在私有 `.env` 中用
`NFI_DNS_SERVER` 调整；不会修改宿主机 DNS。此前启用过代理时，使用以下命令重建服务并清理旧代理；
账户配置和数据库保留，机器人重启后遵循已保存的启动设置，默认保持停止：

```bash
docker compose -f docker-compose.live.yml -p nfi-live up -d --remove-orphans
```

远程服务器可通过 SSH 隧道访问本机地址：

```bash
ssh -N -L 18081:127.0.0.1:18081 用户名@服务器IP
```

## 配置交易账户

从侧栏或“账户与安全”进入“交易账户”（`/trading_settings`）：

1. 填写账户别名、OKX API Key、API Secret、API Passphrase，以及初始交易预算。
   Passphrase 是创建 API 时设置的口令，不是 OKX 登录密码。
2. 点击“验证连接并读取余额”。该操作只读取 OKX 账户身份和 USDT 余额，不下单、不划转资金。
3. 输入当前后台管理员密码，点击“保存并应用（保持停止）”。保存时会再次检查账户和余额。
4. 等待服务加载完成，确认账户 UID、预算和模式。机器人仍为 `stopped`；
   需要在交易页面手动点击“启动”，才允许策略交易。

API 应具有读取及现货交易权限，禁用提现，并设置服务器稳定出网 IP 白名单。
将专用 USDT 划转到 OKX **交易账户**，不要混放其他机器人或手工持仓。
余额读取成功仅证明读取权限有效，不能证明交易权限有效。

使用域名、HTTPS 或内网穿透时，应从实盘后台自己的地址打开页面，再提交账户、Bark 或启动设置。
后台支持浏览器提供的同源请求标记，即使转发层修改 Host 或终止 HTTPS，也可正常保存；
其他来源的请求仍被拒绝。仅发送 `X-Forwarded-Host` 不会绕过来源检查。

初始预算使用 Freqtrade 的 `available_capital`：后续随已实现盈亏变化，
不是最大亏损上限，也不会额外应用模拟盘的 99% 资金比例。
网页最低接受 100 USDT，但实际资金还需满足六个持仓和策略加减仓的最小下单要求。
真实账户余额只读；充值、提现和账户间资金划转在 OKX 操作。

## 修改配置与数据保存

- 已保存密钥不会通过 API 返回浏览器；输入框保持空白，留空表示保留原值。
- 修改或重新加载配置需验证当前管理员密码，并要求机器人处于停止状态。
- 有持仓或未完成订单时禁止修改预算；同一账本有交易历史后，禁止切换到另一个 OKX UID。
  轮换同一账户的 API 密钥时会重新验证身份。
- 初次保存会固定当前已应用的模拟盘配方、OKX 黑名单和 X8 策略副本。
  若已在实盘“策略配方”保存草稿，初次配置账户优先采用该草稿。
  后续修改账户不会自动更新该策略快照，模拟盘配方也不会自动推送到实盘。
- 初始化失败时会返回管理后台，在网页修改设置或使用“重新加载实盘配置”重试。
  此过程不会自动启动交易。

## 策略库、回测与实盘配方

实盘侧栏的“策略库”和“回测”访问独立研究服务。研究采用模拟盘**已保存**的配方及研究策略代码，
并与模拟盘共享研究任务和结果；选择回测策略、下载行情或运行回测不会更换实盘策略或启动交易。
研究配方、实盘参数以及实盘保存的 X8 副本可能不同，不能把研究结果当成完全相同实盘配置的验证。

“策略配方”（`/recipes`）独立管理实盘草稿，展示当前实盘、草稿、模拟盘**已生效**配方及上一份实盘参数。
可调整持仓上限、币池上限、上市天数、成交量、点差和入场滑点限制。
实盘预算仍在“交易账户”配置，手续费取自 OKX；模拟费率和资金比例不参与实盘计算。

1. 编辑实盘参数，或点击“复制模拟盘生效配方到草稿”，然后保存实盘草稿。
2. 对比参数，先停止机器人，并处理全部未平仓交易和未完成订单。
3. 输入当前管理员密码，点击“应用到实盘（保持停止）”并确认。
4. 等待已生效提示；加载后机器人保持停止，核对后再手动启动。

保存草稿不改变已运行的实盘配置。应用前同时检查草稿版本与账户配置版本，避免覆盖其他会话的修改。
“恢复上一份实盘配方”以新版本恢复上一份参数，同样要求密码、确认及无持仓/订单；
加载失败退回管理后台时也可尝试回滚。应用和回滚均保留密钥、预算、数据库、策略副本及启动偏好，
不会自动更新策略代码，也不会因启用了容器自动启动而自动恢复交易。

私有文件均位于忽略提交的 `user_data/live-okx/`：

| 文件 | 内容 |
| --- | --- |
| `.nfi-account.json` | 管理员密码哈希及会话密钥，权限 0600 |
| `live-profile.json` | 账户密钥、预算和固定的策略配置，权限 0600 |
| `.nfi-live-previous.json` | 上一份账户配置，权限 0600 |
| `.nfi-live-recipe.json` | 独立实盘配方草稿，权限 0600 |
| `.nfi-live-recipe-previous.json` | 上一份实盘配方参数，权限 0600 |
| `strategies/NostalgiaForInfinityX8.py` | 独立策略副本 |
| `trades-live.sqlite` | 独立实盘账本 |

文件权限保护不等于磁盘加密；备份同样包含密钥，需要按私密资料保管。
已有旧版 `config.json` / `credentials.json` 的 OKX 部署会迁移到网页管理，
保留原文件、策略和数据库；管理员沿用原登录凭据。

## 本机代理（可选）

若 OKX 直连不可用，本机有 `127.0.0.1:7890` HTTP 代理，可在 Linux 上使用：

```bash
docker compose -f docker-compose.live.yml -f docker-compose.live-proxy.yml -p nfi-live up -d
```

此后重建实盘时继续使用这两个 `-f` 文件。代理监听 Docker 网桥 `172.17.0.1:17891`，
不绑定公网。网桥和本机代理端口可分别用 `NFI_PROXY_BIND`、`NFI_PROXY_HOST_PORT` 调整，
不涉及交易账户凭据。此方式不适用于 Docker Desktop。代理出网 IP 也要符合 API 白名单。

## 停机与恢复

容器默认启动为 `stopped`。可在「设置 → 机器人启动」开启“容器启动／重启后自动启动机器人”，
输入管理员密码并确认后保存。设置在实盘自己的 `.nfi-startup.json` 中持久化，权限 `0600`，
不影响模拟盘。实盘账户需先成功加载才能开启此开关。

修改开关不会立即改变交易状态；开启后，下一次容器启动、重启或重建会自动进入 `running`，
可能发出真实订单。保存账户或重新加载交易配置仍保持停止，需手动启动。
手动“停止”或“暂停开仓”不会关闭自动启动开关。未初始化或初始化失败时不会自动交易。
**停止同时停止已有持仓的策略管理，不会自动清仓。**“暂停开仓”继续管理已有持仓，
但也会停止加仓。X8 保持 `stoploss=-0.99` 和 `stoploss_on_exchange=false`，
不要将其当作严格的小幅止损保障。

允许中断持仓管理时，先在网页关闭自动启动，再停止服务并备份整个目录：

```bash
docker compose -f docker-compose.live.yml -p nfi-live stop freqtrade-live
python - <<'PY'
from datetime import datetime
from pathlib import Path
import shutil

backup = Path('user_data/backups') / ('live-okx-' + datetime.now().strftime('%Y%m%d-%H%M%S'))
backup.parent.mkdir(parents=True, exist_ok=True)
shutil.copytree('user_data/live-okx', backup)
backup.chmod(0o700)
print('备份目录:', backup)
PY
```

恢复使用匹配的配置、策略和数据库，先核对实际持仓及未成交订单，再手动启动。
不要通过删除数据库重置已有实盘。
